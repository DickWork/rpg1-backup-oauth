RPG1 Backups

A private-use utility for backing up the owner's RPG1 game-development SQLite database to the owner's Google Drive.

How it works

  • A local Linux server creates a SQLite backup and verifies its integrity.
  • The open-source rclone application uses Google OAuth authorization to upload dated backup files to the owner's Google Drive account.
  • The backup job is intended to run on a nightly schedule once configuration and a restore test are complete.
  • Database contents, login credentials and OAuth tokens are not hosted on this website or in this public source repository.

Who can use it?

This is a utility for the operator's personal use. It is not a public backup service and does not offer registration or shared storage accounts.

Access and control

Google OAuth grants the authorized rclone client access according to the scopes selected during configuration. The backup process is intended to operate on a specified Google Drive backup folder; that destination folder is an operational setting, not necessarily an OAuth-enforced folder-only permission. The account owner can revoke access through Google Account third-party connections.

For details about information handling, see the RPG1 Backups Privacy Policy.
