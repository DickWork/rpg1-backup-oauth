Privacy Policy

Effective October 10, 2026

RPG1 Backups is a personal-use utility intended to make verified copies of the operator's RPG1 SQLite development database and place those copies in the operator's own Google Drive. It is not a public service and does not accept public user registrations.

Information accessed and processed

When the owner authorizes the utility, rclone obtains Google OAuth credentials and may access Google Drive file names, identifiers, metadata and file content, according to the scopes granted. The local backup process reads the owner's specified RPG1 database and uploads generated backup files and verification information to the configured destination.

The operational configuration restricts intended uploads to the designated backup folder. Depending on the authorized OAuth scope, Google's permission grant may cover more than that folder. The owner should review the scope on Google's consent screen before approval.

How information is used

Google Drive access is used to create, check, list, retrieve and manage the owner's backup files as needed to maintain and restore backups. It is not used to profile users, deliver advertising or sell information. No RPG1 database or OAuth credential is published on this public website.

Storage and security

The working database and local snapshots reside on the owner's Linux machine. Remote copies reside in the owner's Google Drive account. OAuth authorization details are intended to be stored in an access-restricted rclone configuration on that machine, separate from the public GitHub repository and game-development code. The operator controls those resources and is responsible for securing, retaining and deleting backup copies.

Sharing

The utility does not intentionally distribute backup contents or Google credentials to third parties. Google processes authorized Drive API requests to provide Google Drive storage. GitHub hosts these informational webpages, and both platforms may process ordinary access logs according to their own policies. No advertising or third-party analytics have been intentionally added to these pages.

Retention and deletion

Backups are intended to be retained as dated versions under a schedule chosen by the owner. The owner may delete local or Google Drive backups at any time. Removing or revoking the rclone authorization stops future authorized Drive API access but does not automatically delete existing backups.

Control and revocation

The owner can review or revoke connected-app access using Google Account third-party connections. Backup files can be managed directly in Google Drive. An authorized client may need to be configured again after revocation.

Changes and contact

This policy may be updated if the utility's actual backup implementation or scope of access changes. Changes will be published here. For questions about this informational project, contact the maintainer through the public source repository.
